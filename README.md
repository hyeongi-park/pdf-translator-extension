# pdf-translator-extension
일반적으로 크롬에서 pdf를 열면 원하는 부분을 드래그 후 우클릭을 통해 "Translate section to 한국어"를 선택해서 번역을 볼 수 있습니다.

그러나 특정 경우에는 이 항목이 보이지 않는 경우가 있는데, 이를 대체해주는 익스텐션이라고 생각하면 됩니다. 번역을 원하는 부분 드래그 우클릭 후  "translate blabla" 누르면 번역해줍니다.
기본 옵션은 영어에서 한국어로 번역입니다.
