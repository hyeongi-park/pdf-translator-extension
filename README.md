# pdf-translator-extension
pdf 번역해주는 크롬 익스텐션인데 원하는 부분 드래그 우클릭 후  "translate blabla" 누르면 번역해줍니다.
<img width="1118" height="951" alt="image" src="https://github.com/user-attachments/assets/03d8d1de-2e76-466c-8c7d-f3481c2b35f3" />

그런데 만들고 나서 깨달았는데 그냥 "Translate section to 한국어"를 선택해서 번역을 보는 게 훨씬 더 편하고 좋습니다. 그걸 사용하도록 하세요.
